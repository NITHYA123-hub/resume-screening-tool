# AI Resume Screening Tool

AI Powered Resume Screening & ATS Parsing System using Machine Learning and Streamlit.

## 🚀 Live Demo
Try the app here 👉 
https://resume-screen-phc3mgrkvgajj3v7m6chxy.streamlit.app

## Features
- Resume Text Extraction (PDF, DOCX, TXT)
- ATS Compatibility Score Calculation
- Job Category Prediction
- Side-by-Side Candidate Comparison (with Radar Chart)
- Data Analytics & Visualizations (with Plotly)
- Stored Resumes Data Export (CSV)
- Admin Panel for Model Status

## Technologies Used
- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Plotly
- pdfplumber
- PyPDF2
- python-docx

## Machine Learning
Random Forest Classifier was used for job category classification (achieved 90% accuracy).

## Run Project

```bash
streamlit run app.py
```
